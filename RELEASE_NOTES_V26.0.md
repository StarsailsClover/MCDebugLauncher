# MDL v26.0.0 — Official Release

## v26.0 Official Release

The first official (non-prerelease) build of the v26.0 line. This collapses
the work delivered across Alpha 9 through Alpha 12 into a stable release.

| Alpha 12 | `mdl doctor` environment health check + ROADMAP.md |
